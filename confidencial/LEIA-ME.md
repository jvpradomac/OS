# confidencial/

Esta pasta é ignorada pelo Git (só este arquivo entra). Aqui fica o material sensível que você trouxer para o Claude trabalhar.

- Uma pasta por tema, criada no onboarding a partir do que você quer usar o sistema para fazer. Cada uma com um `README.md` no topo: o que é, estado e próximo passo.
- `inbox/`: arquivos recém-chegados. Peça ao Claude para classificar e mover.

O Claude lê esta pasta na sua máquina. Traga só o necessário: trechos em vez de documentos inteiros, nomes trocados quando der.

O onboarding também cria aqui o `temas.md`: a lista dos seus temas, com o caminho de cada pasta. O `AGENTS.md` aponta para ela.
